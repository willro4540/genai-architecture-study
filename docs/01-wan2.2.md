## 1. DiT 백본 (`wan/modules/model.py`)

VAE latent를 `nn.Conv3d`로 3D 패치화(patch_size=(1,2,2))해서 시퀀스로 만들고, 3D RoPE(시간/높이/너비 3축 분리) + T5 cross-attention + AdaLN 스타일 타임스텝 조건화를 쓰는 DiT.

```python
def rope_apply(x, grid_sizes, freqs):
    # 위치 임베딩을 시간축/높이축/너비축 3개로 쪼개서 각각 회전 위치 인코딩 적용
    n, c = x.size(2), x.size(3) // 2
    freqs = freqs.split([c - 2 * (c // 3), c // 3, c // 3], dim=1)
    ...
```

타임스텝을 6개 파라미터(shift/scale/gate × self-attn, ffn)로 projection해서 모든 블록에 modulation 적용:
```python
self.modulation = nn.Parameter(torch.randn(1, 6, dim) / dim**0.5)
...
e = (self.modulation.unsqueeze(0) + e).chunk(6, dim=2)
y = self.self_attn(self.norm1(x).float() * (1 + e[1]) + e[0], ...)
x = x + y * e[2]
```

출력 헤드는 zero-init:
```python
nn.init.zeros_(self.head.head.weight)   # 훈련 초반 벡터장을 거의 0으로 눌러서 안정화
```

## 2. "MoE"의 실체 — 사실은 2개의 완전한 14B 전문가 (`wan/text2video.py`, `wan/configs/wan_t2v_A14B.py`)

레이어 내부 토큰 라우팅 MoE가 아니라, **완전히 분리된 140억 파라미터 DiT 두 개**(`high_noise_model`, `low_noise_model`)를 diffusion timestep 경계값(`boundary=0.875`)으로 스위칭:

```python
def _prepare_model_for_timestep(self, t, boundary, offload_model):
    if t.item() >= boundary:
        required_model_name = 'high_noise_model'   # 아직 노이즈 심함 → 구도 형성 전담
    else:
        required_model_name = 'low_noise_model'    # 저노이즈 → 디테일 정제 전담
    ...
```

샘플링 루프(Classifier-Free Guidance 포함):
```python
sample_guide_scale = guide_scale[1] if t.item() >= boundary else guide_scale[0]  # 4.0 vs 3.0
noise_pred_cond   = model(latents, t=timestep, **arg_c)[0]
noise_pred_uncond = model(latents, t=timestep, **arg_null)[0]
noise_pred = noise_pred_uncond + sample_guide_scale * (noise_pred_cond - noise_pred_uncond)
latents = sample_scheduler.step(noise_pred, t, latents)[0]
```
고노이즈 구간엔 guide_scale을 더 세게(4.0) 줘서 프롬프트 방향으로 구도를 강하게 끌고, 저노이즈 구간엔 약하게(3.0) 줘서 과도한 아티팩트를 막음.

`shift` 파라미터(샘플러 쪽, `fm_solvers_unipc.py`)는 노이즈 스케줄을 비선형 재매개변수화:
```python
sigmas = shift * sigmas / (1 + (shift - 1) * sigmas)
```
shift가 크면(예: 12.0) 고노이즈 구간에 샘플링 스텝을 더 많이 배정 — 해상도가 높을수록 초반 구도 형성에 계산을 더 씀. UniPC 솔버 자체는 HuggingFace `diffusers`의 `UniPCMultistepScheduler`를 flow-matching용으로 변환한 것(자체 발명 아님, 1번째 줄 주석에 명시).

## 3. 청크 스트리밍 causal VAE (`wan/modules/vae2_2.py`)

시간축 패딩을 과거 방향에만 줘서 미래 프레임을 절대 참조하지 않게 강제:
```python
class CausalConv3d(nn.Conv3d):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self._padding = (
            self.padding[2], self.padding[2],
            self.padding[1], self.padding[1],
            2 * self.padding[0], 0,          # 시간(t) 축: 과거쪽만 패딩
        )
        self.padding = (0, 0, 0)

    def forward(self, x, cache_x=None):
        # cache_x = 이전 청크의 마지막 프레임들. 청크 경계에서 정보 손실 없이 이어붙임
        if cache_x is not None and self._padding[4] > 0:
            x = torch.cat([cache_x, x], dim=2)
            ...
```
`ResidualBlock`은 conv 하나 지날 때마다 `feat_idx[0] += 1`로 캐시 슬롯을 하나씩 소비 — 레이어별 시간축 수용영역(receptive field)에 정확히 맞는 만큼만 과거 상태를 들고 다니는 유한상태 순환계.

`AvgDown3D`/`Down_ResidualBlock`: 다운샘플링을 "학습되는 conv 경로"와 "파라미터 없는 순수 평균 경로"(`x.mean(dim=2)`) 둘로 나눠 residual로 더함 — ResNet identity shortcut을 공간 압축까지 확장한 안정화 트릭.

## 4. 오디오/포즈/얼굴/레퍼런스이미지 — 조건 신호별 차등 주입 전략

같은 T2V DiT 백본에 조건 신호가 늘어날 때마다 통제 강도에 따라 다른 방식으로 주입:

| 조건 신호 | 주입 방식 | 파일 |
|---|---|---|
| 텍스트(T5) | 모든 40개 블록에 cross-attn | `model.py` |
| 레퍼런스 이미지(CLIP) | 텍스트와 concat + 이미지 전용 K/V 한 번 더 | `animate/model_animate.py` |
| 포즈 | patch embedding에 그냥 덧셈 | `animate/model_animate.py` |
| 얼굴 모션 | 5개 블록마다 1번, 전용 cross-attn(residual) | `animate/face_blocks.py` |
| 오디오(s2v) | 지정된 소수 블록(`inject_layer=[0,27]`)에만, 전용 cross-attn(residual) | `s2v/audio_utils.py` |

오디오 주입(`AudioInjector_WAN`)과 얼굴모션 주입(`FaceBlock`)은 완전히 동일한 패턴 — DiT feature가 Query, 조건 신호가 Key/Value인 cross-attention을 소수 레이어에만 residual로 더함. 얼굴 모션은 LIA(Latent Image Animator) 논문 구조를 그대로 가져와, `Direction` 모듈이 QR 분해로 20개의 직교(orthogonal) "모션 축"을 만들어 얼굴 표정을 저차원 해석 가능한 공간에 투영:
```python
class Direction(nn.Module):
    def forward(self, input):
        Q, R = custom_qr(self.weight + 1e-8)   # 20개의 서로 직교하는 512차원 벡터
        input_diag = torch.diag_embed(input)
        return torch.sum(torch.matmul(input_diag, Q.T), dim=1)
```

## 5. 인프라 — T5/FlashAttention/FSDP/Ulysses는 전부 기존 구성요소 재사용

- **T5 텍스트 인코더**(`t5.py`): HuggingFace T5 구현 그대로(`# Modified from transformers.models.t5.modeling_t5`). umT5-xxl, 인코더만 사용. attention에 scale 없이 상대위치편향(`T5RelativeEmbedding`)을 더하는 원조 T5 방식.
- **FlashAttention 래퍼**(`attention.py`): `cu_seqlens`(누적 시퀀스 길이)로 가변 길이 배치를 패딩 없이 이어붙여 처리. FA3→FA2→PyTorch SDPA 3단 폴백.
- **FSDP**(`distributed/fsdp.py`): PyTorch 표준 `FullyShardedDataParallel`을 블록 단위로 감쌈. Wan 고유 로직 없음.
- **Ulysses Sequence Parallel**(`distributed/ulysses.py`): DeepSpeed Ulysses(arXiv:2309.14509) 그대로. all-to-all 통신으로 "시퀀스-분산" ↔ "헤드-분산" 상태를 전환해서 attention을 로컬로 완결시킴.

## 6. 동역학적 종합

- **시간축 왜곡(shift)**: 적분 예산을 노이즈 구간별로 재배분
- **스위칭 시스템(high/low noise)**: 서로 다른 난이도 구간에 별도 벡터장(파라미터) 할당, guide_scale도 구간별로 다르게 스케줄링(제어이득 스케줄링과 유사)
- **zero-init**: 훈련 초기 벡터장을 거의 0으로 눌러 안정화(항등사상에서 점진적으로 개방)
- **유한 캐시(causal VAE)**: 무한 길이 시퀀스를 유한 상태 순환계로 압축, 캐시 깊이=레이어별 수용영역
- **통신 위상전이(Ulysses)**: all-to-all로 텐서의 분산 축을 뒤바꿔 로컬 계산을 가능케 함

Wan2.2 고유의 기여는 **DiT 백본 설계 + 2-전문가 타임스텝 스위칭 + 조건 신호별 차등 주입 전략 + 청크 스트리밍 causal VAE**이고, 나머지(T5/FlashAttention/UniPC/FSDP/Ulysses)는 검증된 인프라를 그대로 가져다 쓴 것.
