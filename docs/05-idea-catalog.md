# 아이디어 개발용 패턴 카탈로그

모델 이름이 아니라 **"어떤 문제/상황에 쓰는가"** 기준으로 찾아보는 인덱스. 나중에 뭔가 만들다가 아래와 비슷한 벽에 부딪히면, 해당 메커니즘을 참고해서 자기 문제에 맞게 변형해서 쓸 것.

## 시퀀스/데이터가 너무 길어서 메모리에 다 못 올림

- **청크로 나눠 처리해도 전체를 한 번에 처리한 것과 결과가 같아야 함** → `CausalConv3d` + `feat_cache`(레이어별 유한 캐시, 캐시 크기 = 레이어 수용영역) — [01-wan2.2.md](01-wan2.2.md) §3
- **캐시를 계속 늘리지 않고 고정 크기 상태로 압축하고 싶음(무한 컨텍스트)** → KDA의 delta-rule 유한상태 행렬 `S_t`(시퀀스 길이 무관 고정 크기, 매 스텝 지우기+쓰기) — [03-kimi-k3-kda.md](03-kimi-k3-kda.md)

## 기존 완성된 모델/파이프라인에 새 조건(입력)을 추가해야 하는데, 안정성이 걱정됨

조건을 얼마나 세게 반영해야 하는지에 따라 고르는 스펙트럼 (약→강):
1. 그냥 덧셈(가장 약함, 계산 거의 안 늘어남) — Wan2.2 포즈 조건화, [01-wan2.2.md](01-wan2.2.md) §4
2. 기존 조건(텍스트 등)과 concat + 전용 K/V 한 번 더 — Wan2.2 레퍼런스 이미지, [01-wan2.2.md](01-wan2.2.md) §4
3. 소수 레이어에만 전용 cross-attention을 residual로 추가 — Wan2.2 오디오(s2v)/얼굴모션(animate), [01-wan2.2.md](01-wan2.2.md) §4
4. 모든 레이어에 양방향 cross-attention, 게이트로 결합 강도 학습(가장 강함, 비쌈) — LTX-2.5, [04-ltx-2.5.md](04-ltx-2.5.md)

→ **"이 조건이 결과물의 세밀한 디테일까지 결정해야 하는가, 큰 틀만 살짝 건드리면 되는가"**로 스펙트럼에서 위치를 고르면 됨.

## 깊은 네트워크(레이어를 많이 쌓은 구조)를 만들었는데 훈련이 발산/불안정함

- **새 서브모듈을 기존 네트워크에 붙일 때** → 출력층 zero-init으로 "처음엔 아무것도 안 바꾸는" 상태에서 시작 — [01-wan2.2.md](01-wan2.2.md) §1
- **레이어 간 정보 흐름 자체(residual)를 재설계해야 할 때** → 이중확률행렬(doubly-stochastic) 제약(Sinkhorn-Knopp)으로 전이행렬의 스펙트럴 반경을 1 이하로 구조적으로 고정 — [02-deepseek-v4-mhc.md](02-deepseek-v4-mhc.md)
- **두 서브시스템을 결합하는데 한쪽이 다른 쪽을 망가뜨릴까 걱정될 때** → AdaLN-Zero 게이트로 결합 강도를 학습 가능한 값으로(초기값 0 근처) — [04-ltx-2.5.md](04-ltx-2.5.md)

## 하나의 모델/함수로 너무 이질적인 난이도의 하위 문제를 다 커버해야 함

- **입력의 "국면(phase)"에 따라 완전히 다른 전략이 필요할 때** → 국면 판별 기준으로 아예 다른 파라미터(전문가)를 통째로 스위칭 + 국면별로 다른 게인(guide_scale) 부여 — Wan2.2 high/low-noise, [01-wan2.2.md](01-wan2.2.md) §2

## 매칭/라우팅을 학습해야 하는데(누가 누구와 짝지어질지) 결과가 폭주하면 안 됨

- **softmax만 쓰면 한쪽 방향만 정규화됨(행 합만 1)** → Sinkhorn-Knopp으로 행/열을 번갈아 정규화해서 양쪽 다 1로(이중확률) — [02-deepseek-v4-mhc.md](02-deepseek-v4-mhc.md)

## 온라인으로(배치 재학습 없이) 메모리를 갱신해야 함

- **새 정보가 들어올 때마다 오래된 관련 정보를 지우고 새로 써야 함** → delta rule(지우기 항 + 쓰기 항을 분리해서, 오차만큼만 수정) — [03-kimi-k3-kda.md](03-kimi-k3-kda.md)

## 서로 다른 좌표계/차원을 가진 두 신호를 하나의 attention으로 섞어야 함

- **억지로 같은 공간에 투영하지 않고** → 각 신호가 자기 좌표계의 위치 인코딩(RoPE)을 유지한 채, cross-attention의 Q/K에 각자 것을 따로 적용 — LTX-2.5 비디오(3D)-오디오(1D) cross-attn, [04-ltx-2.5.md](04-ltx-2.5.md)

## 검증된 인프라를 언제 새로 안 만들고 가져다 써도 되는가

Wan2.2 사례([01-wan2.2.md](01-wan2.2.md) §5)가 보여주듯, 텍스트 인코더(T5)/attention 커널(FlashAttention)/샘플러(UniPC)/분산처리(FSDP, Ulysses)는 전부 기존 라이브러리·논문 구현을 그대로 가져다 씀 — **자체 발명은 진짜 핵심 아이디어(2-전문가 스위칭, 조건 주입 전략, causal VAE)에만 집중하고 나머지는 검증된 것 재사용**하는 것도 하나의 전략.
