# LTX-2.5 (Lightricks) — native 오디오-비디오 통합 심층분석

- 저장소: https://github.com/Lightricks/LTX-2 (오픈 웨이트, monorepo: ltx-core/ltx-pipelines/ltx-trainer)
- 22B 비대칭 dual-stream diffusion transformer, 네이티브 4K HDR, 최대 20초, 50fps

## Wan2.2 s2v와의 근본적 차이

Wan2.2의 s2v는 "완성된 T2V 백본에 소수 레이어만 오디오 cross-attn을 이식"하는 애드온 방식(`docs/01-wan2.2.md` §4 참고). LTX-2.5는 **모든 블록마다 비디오/오디오가 대등한 1급 시민**.

## `BasicAVTransformerBlock` (`packages/ltx-core/src/ltx_core/model/transformer/transformer.py`)

```python
if audio is not None and video is not None:
    # Q: Video, K,V: Audio
    self.audio_to_video_attn = Attention(query_dim=video.dim, context_dim=audio.dim, ...)
    # Q: Audio, K,V: Video
    self.video_to_audio_attn = Attention(query_dim=audio.dim, context_dim=video.dim, ...)
```

모든 블록에 **양방향(bidirectional) cross-modal attention**이 존재. forward:

```python
if run_a2v and not video.cross_attn_skip_all:
    ...
    vx = vx + (
        self.audio_to_video_attn(a2v_vx_scaled, context=a2v_ax_scaled, ...)
        * gate_out_a2v                              # 학습되는 게이트 (AdaLN-Zero)
        * video.cross_attn_perturbation_mask
    )
if run_v2a and not audio.cross_attn_skip_all:
    ...
    ax = ax + (
        self.video_to_audio_attn(v2a_ax_scaled, context=v2a_vx_scaled, ...)
        * gate_out_v2a
        * audio.cross_attn_perturbation_mask
    )
```

## `Modality` 데이터클래스 (`modality.py`)

비디오와 오디오는 서로 다른 위치 좌표계를 씀:
```python
@dataclass(frozen=True)
class Modality:
    latent: torch.Tensor       # (B, T, D)
    positions: torch.Tensor    # video: n_pos_dims=3(시간,높이,너비) / audio: n_pos_dims=1(시간)
    ...
```
cross-modal attention 시 `pe=video.cross_positional_embeddings, k_pe=audio.cross_positional_embeddings`처럼 **각자의 좌표계 RoPE를 Q/K에 따로 적용**해서 대응시킴 — 이질적 차원의 두 신호를 억지로 하나의 공간에 투영하지 않음.

## 동역학적 해석

비디오 상태(vx)와 오디오 상태(ax)는 각자 self-attn/FFN으로 독립적으로 진화하는 **결합된 동역학계(coupled dynamical system)**. 매 레이어마다 `gate_out_a2v`, `gate_out_v2a`라는 **학습된 결합 강도(coupling strength)**로 서로 영향을 주고받음. 이 게이트는 AdaLN-Zero 방식으로 초기화되어 훈련 초반엔 거의 0(두 계가 독립적으로 출발) → 학습이 진행되며 서서히 결합이 열림.

Wan2.2가 "오디오를 몇 개 레이어에만 값싸게 끼워 넣는 애드온"이라면, LTX-2.5는 "처음부터 두 계를 매 레이어 대칭적으로 결합해 함께 진화시키는" — 파라미터·연산 비용은 크지만 "native audio-video"라는 표현에 실제로 부합하는 설계.
